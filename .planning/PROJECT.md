# Project: Rushikesh Tawade Portfolio & Resume Website

## Overview
A modern, premium, high-performance personal portfolio and interactive resume website for Rushikesh Tawade (Full Stack Developer & Software Engineer). Features a bespoke developer-centric aesthetic with deep navy/slate backgrounds, refined cyan/indigo accents, smooth micro-interactions, responsive mobile navigation, filtered project showcase, career timeline, education & certification cards, integrated interactive resume viewer with PDF print/download support, and an accessible contact form with instant validation.

## Key Goals
- Showcase technical proficiency across Frontend, Backend, Databases, and Tools.
- Present featured projects with live demos, code repositories, architecture overviews, and categorized filtering.
- Provide a clean experience/education timeline and verified credentials.
- Integrated resume view and one-click PDF generation/download.
- Deliver 100% responsive, high-performance, accessible UI with zero build dependencies, instantly previewable.
- Keep all personal data, links, projects, and work history cleanly structured in a dedicated data file for effortless user modification.
